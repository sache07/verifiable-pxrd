# Limitations

- Exact StructureMatcher recovery is sensitive to the benchmark's explicit periodic
  representation and can reject powder-near-equivalent structures.
- Comparable-fit Rwp can favor incorrect structures and is reported alongside, not in
  place of, exact recovery.
- Closed-model Codex and ChatGPT results depend on model snapshots, product harnesses,
  service tiers, and stochastic inference that cannot be reconstructed from source code
  alone.
- DICVOL14 is not bundled pending redistribution review.
- The repeatedly inspected 20-case inference panel is development evidence, not a fresh
  final test set.

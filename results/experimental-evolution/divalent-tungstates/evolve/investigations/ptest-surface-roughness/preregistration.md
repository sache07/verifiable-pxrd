# Surface-roughness challenge preregistration

## Claim under test

The c02 and c05 v1/v2 projects omitted a Bragg--Brentano surface-roughness
correction while compensating low-angle intensity behavior with phase fractions,
polarization, or texture. Starting from all v1 endpoints plus the v2 c02/c05
endpoints, retain the full submitted model and challenge Suortti A then B from
one common physical start. c01, c03, c04, and c06 are specificity controls.

## Predictions and decision rule

- Support requires physical fresh-replay D improvement in both independent
  endpoints of at least one target case, with finite interior parameters and
  coherent fraction movement. Controls should return toward a neutral
  correction or remain essentially unchanged.
- If c05 improves despite its retained texture, v3 should establish global
  angle-dependent intensity corrections before choosing a phase texture axis;
  if c02 improves, the same ordering also protects weak-phase fractions.
- Broad control improvements, bound hits, instability, or stored-Rwp-only gains
  reject a reusable rule. This is a mechanism test; no fitted A/B value or
  numerical bound is transferable to the package.

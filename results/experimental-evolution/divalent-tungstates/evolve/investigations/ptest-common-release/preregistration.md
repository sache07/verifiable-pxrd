# Staged common-profile release preregistration

## Claim under test

v2's sharp-lower-envelope wording caused c02, c03, c04, and c06 to freeze an
inadequate common profile before phase-width attribution. Starting from each
fresh v2 endpoint, retain inventory, structures, background, angular terms,
and all accepted phase size/strain terms. Release nonnegative common W, then U,
then X from the submitted values, giving only zero-valued U/X small positive
starts when challenged. c05 is included as a control because its U/W/X terms
were already jointly refined and it was the only v2 profile improvement.

## Predictions and decision rule

- Support requires material fresh-replay D improvement in most of the four
  underfit cases, without physical or inventory failure, and no meaningful c05
  regression. Interior fitted common terms and a lower stored Rwp strengthen
  the interpretation; bound hits or replay/stored-fit disagreement weaken it.
- Improvement confined to c04 would be insufficient for a general package
  rule, because that case is already known to have a large profile ceiling.
- If common release helps but leaves c04 far from its demonstrated ceiling,
  test bounded SH/L separately rather than adding it to this intervention.
- If c05 remains profile-limited, test texture-axis selection independently;
  do not attribute an intensity-ratio error to widths.

This is a diagnostic on learned projects, not prospective validation. No
fitted result or numeric start from this test may enter a reusable package.

# v1 package review and prospective screen

## Evidence basis

The attempt ledger and `b001-synthesis.md` show that P0 already solves phase inventory and analogue construction. Avoidable losses arise after discovery: simulator values become priors, sources/parents receive unequal flexibility, correlated nuisance branches are selected by training Rwp, negligible effects are retained, and final physical warnings are disclosed rather than rejected.

## Intervention

`packages/v1/guidance.md` is a guidance-only package (419 words). It adds no executable helper because every successful operation already appears in P0 workspaces. It asks for:

- strict blindness to generator, frozen-case and scorer values;
- physical screening before expensive source refinement;
- comparison of multiple sources or analogue parents under one restrained whole-pattern model, without excluding ordered multication parents;
- repeat deletion/residual tests for trace assignments whenever the inventory changes;
- fixed-coordinate inventory and nuisance staging before profile effects or structure;
- a second plausible nuisance start and rejection of boundary/correlated branches;
- evidence above counting noise before retaining an effect;
- a hard physical and GPX/CIF/profile consistency gate.

The package explicitly preserves residual-led completion and chemical framework substitution. It forbids chemistry-fixed fractions but allows chemistry as a plausibility and mass-balance check.

## Decision rule and risks

The initial screen succeeds only if every case is at least 80 with physical pass and the intended behaviors are visible in its trajectory. A high score reached through simulator leakage or an invalid branch is not evidence for v1. If a case fails, inspect adherence and the actual mechanism, then edit or replace only the smallest ineffective instruction before rerunning unresolved cases.

The main risk is over-conservatism: stable coordinates can underfit real structural mismatch, and a second nuisance start costs attention. The wording therefore permits supported coordinate refinement and scientifically justified source repair; it rejects only unsupported motion, unequal comparisons and unstable branches. No numerical values from this batch or LAB.md are shipped.

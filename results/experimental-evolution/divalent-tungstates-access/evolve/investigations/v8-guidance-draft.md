## A. Prose-only construction and terminality gate

# Close every serious choice, then finish once

Work from the specimen inputs, pattern, and frozen index. Build ordinary phases
first and reject inherited structural defects. Map coherent residual families
in the best complete state. Every serious formula/topology family, including
one clean physical representative of each serious ordinary framework, must
reach the same mature comparison: clone one shared state, seed each candidate
from a symmetry-compatible indexing of the full linked family, then give its
cell, coordinates and supported profile/intensity terms equal adaptation. A
metric from only a convenient subset is an alias, not formula proof. Numerical
failure remains unknown; a lower-symmetry candidate cannot eliminate a
higher-symmetry family merely because it received safer or deeper methods.
Stop discrete search at physical closure.

For one genuinely unassigned family, form a short reaction-balanced formula
list and retain symmetry-diverse parents from substituted chemistries; do not
restrict retrieval to sample elements. Normalize equivalent settings before
ranking. If positions index but accepted-reflection intensities remain
systematically reversed, test symmetry-allowed ordered site registries before
extra phases, texture or nuisance terms. Early Rwp, substitution count and a
replay-stable decoy are not decisive.

Finish the retained model in order: scales/background, cells and calibration,
supported coordinates, then supported phase/profile/specimen terms. Broad
coherent residuals, gross GOF or near-bound broadening mean a source,
symmetry/registry or profile choice remains open even when replay is stable.
Roll back terms outside supplied laboratory ranges, pinned at tested bounds or
inseparable from correlated alternatives.

Only at physical, profile-complete closure save `final.gpx` and run the supplied
bounded polish exactly once:

```bash
$GSAS2_PYTHON learned/staged_polish.py final.gpx polished.gpx inputs
```

Accept only a converged physical branch. Afterwards perform read-only geometry,
replay and export checks; further refinement means the input was not terminal.
Re-export all outputs from the exact submitted project.

## B. Helper-assisted variant

Use A's prose, shortened only enough to document a small preflight command.
Before the bounded polish, the preflight would read a solver-authored candidate
manifest plus the complete GPX, fail closed when a serious formula/topology
family lacks the same mature-state lineage or development stages, and report
occupied oxide O--O contacts without modifying a model.
It must contain no source IDs, case IDs, answer coordinates, hidden thresholds,
or chemistry-specific rules. This alternative requires a local static test and
an isolated procedure/behavior test before freezing; it is not licensed merely
by v7's source omissions.

# v4 design draft: topology coverage with an early complete checkpoint

Status: cycle-1 v1-v3 are unpromotable and P0 remains incumbent. The prospective b003 full-reference Mn3WO6 comparison is complete and cycle 2 is open; v4 predictions are finalized before freezing.

## Evidence

- v3's reflection-family closure rule is useful but incomplete. It recovered b001-c05 3/3 and harder-Zn 2/3, showing that stopping structure search and completing an accepted transferred framework can repair inventory/profile failures.
- The same package regressed the ordinary four-phase c03 case by 21.82 points. All three runs had the exact inventory; only one recovered. The failures were execution failures after closure, including extensive same-formula WO3 work and weak final coordinate/profile convergence. More search guidance can displace ordinary refinement even when no phase is missing.
- c06 selected R-3 Mn3WO6 in 2/3 runs, but the remaining run committed to P212121 Mn2WO6. Harder-Mn selected C2/c Mn3WO6, P21/c Mn2WO6, and P21/c Mn2WO5; none constructed the surviving R-3 Cd3TeO6 parent. Formula balance alone therefore does not preserve topology diversity.
- The final harder-Mn run systematically compared 136 A2BO5 frameworks and achieved a respectable wrong-formula fit, while never building R-3 Mn3WO6. This is the opposite of the intended small shortlist: breadth within one formula consumed the attention needed to cover distinct formula/symmetry families.
- Solver trajectories routinely spend substantial early attention reading the autonomous-research, generator, and scorer sources even though P0 already specifies the output contract. A complete physical GPX checkpoint saved early would protect against later search or refinement dead ends.
- P0 selected exact R-3 Mn3WO6 3/3 on b003, but recovered 0/3 at a mean of 45.75. Two runs chose physically flagged WO3 for only 0.049/0.124 Rwp-point gains over clean alternatives; the clean exact-inventory run still stopped at D 2.786. Physical tie-breaking and post-closure completion are therefore distinct replicated targets.

## Leading intervention

Ship concise guidance only; no executable helper. Ask the solver to begin from the specimen inputs and library rather than the evolution/controller sources, and to save a replayable physical model as soon as the ordinary phases are credible.

For a genuinely unassigned reflection family, search exact composition first. If transfer is needed, organize candidates by target formula and distinct symmetry/coordination topology, retaining one chemically nearest physical parent per topology rather than screening many records from one formula. The shortlist must cover topology families before any one receives deep optimization. Compare serious candidates in the same multiphase state with equal cell, heavy-coordinate, and profile adaptation.

After every coherent family is indexed, freeze phase identity. Return to the best complete checkpoint and refine the accepted model in a simple sequence: cells/scales/background, heavy and then physically bounded light-atom coordinates, calibration/specimen effects, then only residual-supported phase profile terms. Same-formula replacement is reopened only for physical invalidity or a broad positional/intensity mismatch that coordinate refinement cannot repair. Keep a complete verified fallback throughout.

This deliberately removes v3's detailed procedural prose. The behavioral target is topology coverage before optimization and reliable completion after closure, not more candidate enumeration.

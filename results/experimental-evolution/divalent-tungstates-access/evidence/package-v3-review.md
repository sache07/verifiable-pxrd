# v3 package review

v2 is complete and unpromotable: aggregate delta -3.6, noise 7.0, with c03,
c05 and harder-Zn regression-gate failures. v3 is a guidance-only replacement
for v2. It preserves the common-state rule
that made v2 c02 3/3 recovered and caused every c06 run to construct the
Mn3TeO6-derived R-3 route. Plausible additions and replacements stay in the
best multiphase project; stable scale collapse is required for rejection and
numerical failures remain unknown.

It narrows cross-chemistry search to a coherent reflection family not indexed
by accepted phases or ordinary plausible precursors/products. This targets the
post-closure search drift seen on c03 and c05, where formulas were already
present but intensity/profile residuals consumed attention on more frameworks.
Once coherent families are assigned, the package explicitly stops library
search and returns to ordinary joint refinement.

Harder Zn completed at 91.11/28.88/31.73, mean 50.58 versus P0 72.28. All
three submitted exact ZnWO4 + WO3 + ZnO fractions and all used a two-element
CoMoO4 parent. The recovered run escaped a wrong transferred-coordinate basin
through a broader set of physical coordinate starts, selected clean P21/c WO3
and completed texture/profile refinement. The failures retained weak
major/WO3 coordinates while pursuing additional models or profile grids. v3
therefore adds a physical coordinate-basin restart when an accepted
transferred framework misfits intensities at its own reflections.

It also requires comparable adaptation depth before candidate ranking. In the
failed v2 c06 replicate, Pnnm Mn2WO5 led R-3 Mn3WO6 by only 0.18 Rwp point
after cell-only convergence and then received all later coordinate/profile
work. Another replicate reversed the same provisional ordering after deeper
relaxation. Early fits therefore cannot overrule a chemically economical,
stoichiometrically supported topology.

The second harder-Mn v2 run independently repeated this mechanism with the
tier-2 parent: R-3 Mn3WO6 reached Rwp 15.13, P21/c Mn2WO5 reached 14.70, and
only Mn2WO5 then received deep coordinate/profile adaptation. Its final score
was 31.67 (D 10.823), with the hidden R-3 phase absent.

The final harder-Mn run exposed a complementary miss. It assigned the
unindexed family to Mn2WO6, selected a Y2WO6-derived P212121 model, and never
constructed the surviving tier-2 R-3 Mn3WO6 route. Its physical three-phase
branch remained near Rwp 14.67%, after which it launched 15 texture screens
and hit the 14,400-second limit without writing a submission. This is a
scientific attention failure, not an evaluator error, and its invalid score is
retained. v3 therefore keeps a small reaction-balanced set of plausible
stoichiometries alive for a genuinely unassigned family before framework
transfer; the small-set and family trigger constraints avoid v1's broad-search
sprawl.

Finally, v3 makes accepted-model completion explicit: phase-wise
symmetry-allowed coordinates, well-resolved/heavy sites before weak light-atom
substructures, then specimen/calibration and phase-specific profile terms with
physical rollback and fresh replay. This follows successful P0/c03/c05/Zn
sequences and addresses exact-inventory failures with weak site accuracy.

No executable helper is included. Existing solvers already demonstrate the
needed refinement operations; a universal coordinate or nuisance optimizer
would risk over-refining weak light atoms and recreating known nonphysical
branches. The package contains no case values, structures, hidden effects or
lookup rules.

The prospective predictions were finalized before freezing or launching any
v3 solve. The package is ready to freeze unchanged for the six-case panel.

high reasoning receives one user message containing the exact task prompt and the
complete numerical pattern, with no tools, developer message, code execution, or
persistent workspace. It is an API-controlled LLM-only condition, not a claim
about the exact ChatGPT product UI.

attachments expose only the first 1,000 rows, which would truncate these 8,501-row
patterns at 14.99 degrees two-theta and invalidate the comparison.

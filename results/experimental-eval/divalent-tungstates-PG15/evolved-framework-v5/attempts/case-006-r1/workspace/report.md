# Powder XRD phase analysis

The crystalline pattern is modeled as single-phase triclinic CuWO₄ (space group P -1), with a normalized crystalline weight fraction of 1.0000. CuWO₄ is the chemically ordinary 1:1 product of CuO + WO₃ at 800 °C. Its diagnostic low-angle reflections and the dense high-angle multiplet sequence are all reproduced by one lattice; no coherent residual family remains that supports CuO, WO₃, or another crystalline phase.

The frozen COD exact-composition entries are high-pressure CuWO₄ determinations. COD 4000806 supplied the physically correct P -1 CuWO₄ topology and a close coordinate start; its compressed metric was adapted to the ambient CuWO₄ peak family, then the full cell and heavy- followed by light-atom coordinates were refined. The final cell is a = 4.709314 Å, b = 5.843975 Å, c = 4.882601 Å, α = 91.65596°, β = 92.53356°, γ = 82.74936°. The refined structure has ordinary distorted CuO₆ and WO₆ coordination (shortest Cu–O about 1.94 Å, shortest W–O about 1.78 Å; no unphysical contacts).

The full-grid fit has Rwp = 5.134%, Rp = 3.616%, and reduced χ² = 4.476 using counting-statistical weights. A bounded Bragg–Brentano displacement/surface model and [001] uniaxial microstrain improve reflection shapes. Tests of all supported March–Dollase axes refined to within 1.4% of random orientation and were not retained. Multiple bounded coordinate starts returned the same structural minimum.

The 100 wt% value is normalized over modeled crystalline phases. It does not exclude amorphous material or trace crystalline impurities below the residual/noise detection level. Because this is a one-phase pattern, isotropic crystallite-size broadening is exactly correlated with the instrument Lorentzian term; the size was fixed at 1.0 µm, so that value is not independently determined. Zero/displacement and polarization/ADP/surface terms are also correlated, but this does not materially affect the phase identity or the single-phase normalized fraction. Oxygen coordinates are less precise than the W/Cu substructure and should not be interpreted as a single-crystal-quality determination.

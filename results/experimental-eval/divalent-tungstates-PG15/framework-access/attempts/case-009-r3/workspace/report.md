# Powder XRD phase analysis

The only crystalline phase determined reliably is wolframite-type **MnWO4**, space group **P 2/c**. Its fraction is **1.000 (100 wt%) after normalization over the modeled crystalline phases**. This is not an absolute crystalline yield and does not constrain amorphous material.

The assignment is supported by the full diagnostic peak sequence, including the split reflections near 23.8/24.3 degrees and 30.1/30.6 degrees 2theta and the reflections near 18.6, 31.3, 36.2, and 37.5 degrees. A COD 1520200 wolframite framework was refined against all 8301 points. The resulting cell is a = 4.835863 A, b = 5.762871 A, c = 5.001451 A, beta = 91.21566 degrees, V = 139.3513 A^3. The observed/calculated agreement is Rwp = 4.291%, Rp = 3.366%, Rexp = 3.461%, and goodness-of-fit = 1.242. The difference curve is dominated by small alternating peak-shape residuals rather than independent unmatched reflections.

Chemically plausible alternatives were tested explicitly. Adding Mn3O4 or monoclinic WO3 one at a time produced only approximately 0.30 wt% and 0.17 wt%, respectively, and changed Rwp by less than 0.002 percentage points; Mn3WO6 refined to zero. These values are too sensitive to residual peak shape and background to report as phases. Trace precursor-derived material below roughly a few tenths of a weight percent therefore remains possible but is not determined reliably.

Because no calibrated instrument profile was supplied, the crystallite-size/instrumental Lorentzian terms are exactly correlated; the project uses one physical representative decomposition (isotropic size 0.134 micrometres). Surface-roughness parameters are also correlated, and one was fixed at the prior optimum. The common zero and specimen displacement are correlated as well. These nuisance correlations do not affect the phase identity, but formal lattice/coordinate uncertainties likely understate calibration uncertainty. Oxygen coordinates are less strongly constrained than the W/Mn framework.

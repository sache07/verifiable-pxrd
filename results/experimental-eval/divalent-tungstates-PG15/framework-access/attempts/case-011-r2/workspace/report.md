# Powder XRD phase analysis

The pattern is explained by two crystalline phases: triclinic WO3 (P -1) and rutile-type beta-MnO2 (P 42/m n m). Their refined fractions, normalized over these crystalline phases, are 70.82 wt% WO3 and 29.18 wt% MnO2. This is also chemically plausible for the reported 1:1 W:Mn precursor context at 300 C: the corresponding unreacted stoichiometric mass ratio is about 72.7:27.3.

The WO3 assignment accounts for the dominant low-angle multiplet near 23.4–24.7 degrees 2theta and the remaining WO3 line set. Beta-MnO2 accounts for the weaker features near 29.0, 37.7, 57.0, 59.7, 67.5, and 72.5 degrees. No reproducible unmatched reflections require MnWO4 or a third crystalline phase. A higher-symmetry monoclinic WO3 alternative was explicitly refined with the same profile treatment but remained materially worse (replayed Rwp about 7.84% versus 5.55% for P -1), supporting the triclinic model.

The final GSAS-II replay gives Rwp = 5.546%, Rp = 4.065%, and goodness of fit = 2.061 over all 8301 points. The refined cells are:

- WO3: a = 7.31487 A, b = 7.54472 A, c = 7.70140 A, alpha = 89.9473 degrees, beta = 90.7705 degrees, gamma = 89.9833 degrees.
- Beta-MnO2: a = b = 4.40479 A, c = 2.87643 A.

The phase identities are high confidence. The fractions are less exact because MnO2 preferred orientation, displacement parameters, microstructure, surface roughness, and scale are correlated; a practical uncertainty is roughly +/-0.02 absolute fraction. The detailed oxygen coordinates in low-symmetry WO3 are only moderately constrained by this overlapped powder pattern, so its CIF should be treated as a defensible refined working model rather than a single-crystal-quality determination. Amorphous material, if present, is not quantified, and the reported fractions must not be interpreted as absolute bulk fractions including amorphous content.

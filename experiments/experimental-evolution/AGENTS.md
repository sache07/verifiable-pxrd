# PXRD evolution operator project

`framework/` is shared by every run; change it only deliberately, validate, and record why in DECISIONS.md. `labs/NAME/LAB.md` is the only lab-specific document, written from what the lab knows before analysis, never from evaluation results. A run in `runs/` is a frozen copy: do not edit a run after its researcher has started. Make a new run instead. The researcher documents in each run (PROMPT.md, LAB.md) are the user's; preserve user edits. Keep evaluation data, labels and analyses out of every run folder.

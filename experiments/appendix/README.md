# Appendix experiments

Supporting experiments for the paper appendix live here, separately from the main
agent-adaptation and inference-scaling experiments.

- [Native refinement](native-refinement/README.md): specialist refinement runners,
  pinned dependencies, failure reporting, and result verification.
- [Profile residuals](profile-residuals/README.md): code to reproduce the native
  and shared fixed-profile Rwp distributions for the as-submitted candidates.

Saved outputs are in [`results/appendix/`](../../results/appendix/README.md).
Temporary workspaces and active jobs remain under `.runs/`.
